📦 Smart Delivery Companion

A simple, cost-free smart home solution that enhances delivery success using Home APIs, React, and Firebase.



🚀 Overview

Smart Delivery Companion simulates delivery detection and automates helpful actions around the home. When a package is detected—either by motion sensor or a manual trigger—it lights up the porch, plays a chime, and sends a notification to the user. It’s perfect for homes that want better delivery coordination using affordable tech and no extra hardware.



🛠 Tech Stack

Frontend: React (for delivery simulation)

Backend/Cloud: Firebase (for notifications and logs)

Automation Layer: IFTTT or Home Assistant (to trigger smart lights and sounds)

🧩 Features

Manual or simulated trigger for delivery detection

Automatic porch light activation

Smart speaker sound alerts

Mobile notification via Firebase

Optional image capture or event logging
